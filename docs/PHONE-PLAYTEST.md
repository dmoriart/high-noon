# Physical-phone shooting check

Run with the actual intended Roblox app/device, then repeat against a mouse player in a private server. Simulator screenshots alone do not pass this checklist. Record device class, orientation and observations; do not record personal identifiers.

1. Join an empty server. Can you see the practice targets and understand what to do without extra instructions?
2. Move with the left thumb, aim with the right, and tap Fire; verify exactly one round per press and a hit on the intended target. Repeat while moving and near screen edges.
3. Aim at each target, then track a moving opponent in a match. Note overshoot, slow turning, finger obstruction and accidental shots while dragging to look.
4. Reload an empty cylinder; check the button is reachable, progress is visible, and interruption clears it. Fire/Reload/Jump and the top Roblox menu must not overlap.
5. Test both landscape directions, a smaller supported phone, chat open/closed and death/respawn. Check no stuck input after opening the Roblox menu.
6. Play one full round against a mouse player. Ask whether aim feels controllable and whether opponents are readable; record the situations where it fails.

Decision: change one variable only after recording a reproducible issue. Sensitivity, touch layout and any future assistance need separate trials; do not promise fair cross-device play from screenshots. Des and Josh approve the revised feel before wider promotion.
